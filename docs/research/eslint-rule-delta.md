# ESLint rule delta: `airbnb` base → `@react-native` base

Measured on throwaway branch `spike/eslint-rn-rule-delta` (based on upstream `main` at `711e0d56a`), never merged.
Setup: `npm ci --ignore-scripts`, then `@react-native/eslint-config@0.84.1` and `prettier@2.8.8` installed, `"airbnb"` replaced by `"@react-native"` in `extends`, everything else in `.eslintrc.js` kept.
Tables are generated by `docs/research/eslint-rule-delta-analyze.cjs` from `eslint . -f json` and `eslint --print-config` on one `.tsx`, one `.js` and one test file, before and after.

## Summary

- **A bare swap does not lint.** Airbnb was supplying the `import` plugin and `env.node`. Without them: 3,314 errors, of which 3,113 are "Definition for rule 'import/…' was not found" for our own `import/*` rules, plus 192 `no-undef` (188 `__filename`, 4 `AbortSignal`).
- **With `"import"` added to `plugins` and `env: { node: true }`: 0 errors, 218 warnings** (52 today). The tables below are from the run with `"import"` added but without `env.node`, hence the 192 `no-undef`.
- New warnings: 147 `eslint-comments/no-unused-disable` (disable comments for rules that no longer exist, led by `react/jsx-props-no-spreading` 39, `no-await-in-loop` 13, `react/no-unescaped-entities` 10), 12 `@typescript-eslint/no-shadow`, 2 `jest/valid-expect`, 2 `jest/no-identical-title`, 2 `eslint-comments/no-unlimited-disable`, 1 `eslint-comments/no-unused-enable`.
- **253 rules active today disappear**: 142 core, 58 `react/*`, 32 `jsx-a11y/*`, 21 `import/*`. All have 0 violations today, so re-adding any of them is free.
- **51 rules stay active but weaken**, almost all from error to warning (`eqeqeq`, `no-debugger`, `radix`, `react/no-unstable-nested-components`, …).
- **Only 6 rules are new** from the React Native base (the warnings above).
- **13 of 66 local overrides become dead** (they only switched Airbnb rules off).
- **The parser does not change.** Our top-level `parser` beats the React Native config's `*.js` override, so `.js` files stay on `@typescript-eslint/parser`; `ft-flow` rules do not appear in the effective config. `no-undef` also stays on for TypeScript because our local rule wins.
- Airbnb settings that vanish: `import/extensions`, `import/core-modules`, `import/ignore`, `propWrapperFunctions`, `react.pragma`. Our local `import/extensions` and `import/no-extraneous-dependencies` rules still report 0 violations without them.
- The config no longer loads `jsx-a11y`; `eslint-plugin-jsx-a11y` and `eslint-config-airbnb` become removable devDependencies. `eslint-plugin-import` must stay while we keep `import/*` rules.
- **Prettier** (not enforced by the config; measured with `prettier --list-different`): template options would rewrite 1,173 of 1,176 files; house-like options (double quotes, `printWidth: 100`) would rewrite 1,141 of 1,176.

Not measured: whether the 51 weakened rules or the 253 lost rules matter in practice beyond today's zero counts; behaviour under `lint-staged`; editor integrations.
